# Исследование венчурных инвестиций и финансирования стартапов

## О проекте

Инвестиционной компании необходимо изучить исторические данные о финансировании стартапов, чтобы выявить тенденции рынка и определить перспективные направления для инвестирования.

**Цель проекта** — исследовать структуру и динамику финансирования компаний, сравнить различные типы инвестиций и сформулировать рекомендации для инвестора с позиции 2015 года.

## Задачи

В рамках проекта:

- проведена предобработка данных: обработаны пропуски, дубликаты и аномальные значения;
- созданы дополнительные признаки для анализа длительности финансирования компаний;
- выделены массовые, средние и нишевые сегменты рынка;
- исследованы распределения и типичные объёмы финансирования;
- проанализированы популярность и объёмы различных типов финансирования;
- изучена динамика инвестиционных раундов по годам;
- определены сегменты с растущими объёмами инвестиций;
- рассчитана и проанализирована доля возвращённых средств по типам финансирования;
- сформулированы рекомендации для потенциального инвестора.

## Данные

Исследование проведено на исторических данных о стартапах и их финансировании.

Данные содержат информацию о компаниях, их отраслевой принадлежности, инвестиционных раундах, типах и объёмах финансирования, а также возвращённых средствах.

## Инструменты

**Python · pandas · Matplotlib · Jupyter Notebook**

В работе применялись методы предобработки данных, группировки, сегментации, анализа выбросов, расчёта агрегированных показателей и визуализации данных.

## Основные результаты

- **Рост инвестиционной активности.** Количество раундов финансирования увеличивалось с середины 2000-х годов и достигло максимума в 2013 году.

- **Изменение размеров инвестиций.** Типичный объём одного раунда постепенно снижался, что может свидетельствовать об увеличении количества компаний, привлекающих финансирование на ранних стадиях развития.

- **Структура рынка.** Значительная часть направлений относится к нишевым сегментам, однако основная инвестиционная активность сосредоточена в массовых сегментах.

- **Растущие направления.** Наиболее заметный рост объёмов финансирования наблюдался в технологических сегментах, включая `Internet`, `Apps`, `SaaS`, `Technology` и `Medical`.

- **Типы финансирования.** Венчурное финансирование (`venture`) оказалось наиболее распространённым инструментом, лидирующим по объёму привлечённого капитала и суммарным возвратам средств.

- **Возврат инвестиций.** Различные типы финансирования демонстрируют неодинаковую динамику доли возвращённых средств. Для отдельных типов характерны значительные колебания показателя по годам.

## Рекомендации

С позиции инвестора в 2015 году перспективными направлениями для дальнейшего рассмотрения могут быть:

- **Internet** — интернет-сервисы и онлайн-платформы;
- **Apps** — разработка приложений;
- **SaaS** — программное обеспечение по подписке;
- **Technology** — технологические компании.

Эти сегменты характеризуются ростом объёмов финансирования и высоким интересом со стороны инвесторов.

В качестве одного из основных инструментов инвестирования можно рассмотреть **венчурное финансирование**, учитывая его распространённость, значительные объёмы инвестиций и суммарных возвратов капитала.

При интерпретации результатов необходимо учитывать возможную неполноту данных за 2014 год и ограничения агрегированного анализа. Рост объёмов финансирования не гарантирует доходность отдельных инвестиционных сделок.
